Nombre del proyecto:

Mis pensares

Autor:

Soydanielcc

Descripción: 

Es una biblioteca de todas las cosas que algun dia le quisiera decir.

Historia:

Este proyecto nacio como una confension de sentimientos a traves de una pagina web. Debido a que en un intento en el que fue presentado a la persona correspondiente y no se supo si esa siquiera lo habrio entonces se determino que pasara a ser una biblioteca donde se guardan poesias, musicas y un texto original de una confesión.

Lenguajes usados:

Al principio el mismo funciona directamente con js, algo que se desea cambiar con el fin de proteger y dejar un trabajo mas adecuado con estandares profesionales. Dicho esto ahora los lenguajes:

Html

JavaScript

Css

Python
